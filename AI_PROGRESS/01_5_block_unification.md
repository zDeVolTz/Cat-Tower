# Cat Tower — AI Progress Report
## Этап 1.5 — унификация физических объектов

1. **Цель этапа:** Перевод системы с использования POJO-объектов на использование реальных экземпляров класса `Block` для массива `state.blocks` и нового `PhysicsWorld`. Это подготовит систему к внедрению компонентной логики без изменения текущих алгоритмов Solver-ов.

2. **Изменённые файлы:**
   - `src/game/gameState.js`
   - `src/game/physics.js`

3. **Созданные файлы:**
   - `AI_PROGRESS/01_5_block_unification.md` (этот отчёт)

4. **Как теперь создаётся base Block:** 
   В `gameState.js` (метод `resetGameState`) стартовый базовый блок теперь создаётся через вызов `new Block({...})` с передачей тех же самых базовых аргументов (`x, width, y, typeId, isGolden, color, mass, settled`), что и раньше. Остальные поля (например, squish-анимации) корректно инициализируются внутри конструктора.

5. **Как теперь создаётся dropped Block:** 
   В `physics.js` (метод `handleDrop`) переменная `placed` теперь инстанцируется через `new Block({...})`. Так как логика `handleDrop` сильно зависит от локальных физических переменных (например, `localDropX`, `isUnstableDrop`, `landingSway`), я решил **не переделывать** это через фабрику `Block.createFromMover()`, чтобы не сломать тонкие физические расчёты (адаптация сделана минимально необходимым способом). Те параметры `isTeetering`, `localTilt` и `tiltPivotX`, которые рассчитываются отдельно, присваиваются объекту сразу после его инстанцирования, полностью сохраняя старое поведение.

6. **Как state.blocks связан с PhysicsWorld:** 
   `state.physicsWorld.bodies` продолжает содержать точные ссылки на объекты из `state.blocks`. Разница лишь в том, что теперь это не литеральные объекты, а экземпляры `Block`. Массивы `state.blocks[i] === state.physicsWorld.bodies[i]` идентичны.

7. **Какие старые Solver'ы остались без изменений:** 
   `FallingSolver`, `StabilitySolver`, `CenterOfMassSolver`, `TowerTiltSolver` и вся их интеграция в `PhysicsEngine` остались нетронутыми. Вся логика падений, колебаний и гравитации продолжает работать через них.
